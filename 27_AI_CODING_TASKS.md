# CampusPilot — Ordered AI Coding Tasks

Use one task at a time and test after each major milestone.

## Task 01 — Bootstrap
Create Next.js + TypeScript + Tailwind project.

Done when:
- app runs
- TypeScript passes
- base layout exists

## Task 02 — Design system
Create typography, spacing, buttons, cards, badges and shell.

## Task 03 — Supabase
Configure client/server helpers and environment variables.

## Task 04 — Auth
Implement signup, login, logout and protected routes.

## Task 05 — Database
Apply schema and verify RLS.

## Task 06 — Dashboard
Create real data-driven dashboard.

## Task 07 — Attendance
Implement CRUD and calculations.

## Task 08 — Assignments
Implement CRUD, priority, status and deadline logic.

## Task 09 — Exams
Implement CRUD and countdown/urgency.

## Task 10 — AI Planner
Implement server-side AI route/action, validation and structured output.

## Task 11 — Emergency Mode
Add constrained planning UX.

## Task 12 — Task tracking
Allow study tasks to be marked complete.

## Task 13 — QA
Add errors, loading states, empty states and responsive fixes.

## Task 14 — Security audit
Check RLS, env variables and server boundaries.

## Task 15 — Production
Build, deploy, smoke test and finalize README.

## Agent instruction

Do not proceed to the next task if the current task is broken. Report blockers with:
- error
- suspected cause
- files affected
- proposed fix
