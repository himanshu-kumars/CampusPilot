# CampusPilot — Optional Analytics

Analytics is optional for the MVP and must never block core functionality.

## Useful events

- `signup_completed`
- `login_completed`
- `subject_created`
- `attendance_updated`
- `assignment_created`
- `assignment_completed`
- `exam_created`
- `study_plan_generated`
- `emergency_mode_activated`
- `study_task_completed`

## Privacy rule

Do not send:
- passwords
- auth tokens
- raw private notes
- unnecessary personal identifiers

## Hackathon recommendation

Do not spend significant hackathon time implementing analytics unless the core MVP is already stable.
