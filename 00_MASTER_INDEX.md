## Source of truth

When documents conflict:
1. Security/privacy rules win.
2. PRD wins over implementation convenience.
3. Architecture/API/database definitions win over UI assumptions.
4. Acceptance criteria define whether an MVP feature is complete.

## Build principle

The goal is a working, deployable MVP rather than a large collection of screenshots or static pages.
